# Hybrid Constraints Snapshot interface

We deepen allowed-day truth into one Constraints module behind an immutable Constraints Snapshot: `build` → `evaluate` / `isAllowed` / `scan`, with structured Constraint Denials for forms validators. HolidayProvider and isInvalidDate are build-time adapters; async disabled dates stay Host-fed data. We rejected a flexible query DSL (too wide), a callable boolean-only snapshot (too weak for validator error keys), and exposing DayNormalize/RuleSource on the public Host ceremony (composition stays inside the implementation).

**Status:** accepted
